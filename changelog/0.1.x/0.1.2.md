# 0.1.2 — 2026-10-18

## Changed

- **Response budgets** bound each serialized text-content and structured-output surface to 65,536 UTF-8 bytes, retaining whole entries with explicit counts, preview completeness and continuation. Resume batches using the original input and `nextBatchOffset`; threshold cursors retain candidate positions. ([#6](https://github.com/cyanheads/first-epss-mcp-server/issues/6))
- **CVE inputs** accept whitespace/semicolon lists and Unicode dashes before deduplication; recovery names the calling tool and preserves prioritization severity and policy. ([#8](https://github.com/cyanheads/first-epss-mcp-server/issues/8))
- **History continuation** exposes `previousAnchorDate` and a same-CVE example for the adjacent preceding window, without fetching it automatically or promising snapshot availability. ([#9](https://github.com/cyanheads/first-epss-mcp-server/issues/9))
- **Date/year schemas** advertise blank-or-date syntax, preserve accepted whitespace and calendar checks, and validate the current year at call time; score/history text omits irrelevant CVSS clauses. ([#10](https://github.com/cyanheads/first-epss-mcp-server/issues/10))
- **Capability metadata** aligns package, registry, MCPB, plugins, Docker and README descriptions with the five-tool surface.

## Fixed

- **Service errors** preserve trusted local messages, nonretryable classification and safe HTTP status/retry context without exposing upstream bodies. ([#4](https://github.com/cyanheads/first-epss-mcp-server/issues/4))
- **Unavailable dated snapshots** return `snapshot_unavailable` with the requested date and recovery guidance only for FIRST's recognized HTTP 422 signal; ordinary score omissions remain `not_returned`. ([#5](https://github.com/cyanheads/first-epss-mcp-server/issues/5))
- **History deltas and attribution** round derived differences to nine decimals and apply verified schedule inference consistently to preceding observations, preserving original score precision and separate current-anchor verification. ([#7](https://github.com/cyanheads/first-epss-mcp-server/issues/7))
