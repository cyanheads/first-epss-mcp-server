# 0.1.1 — 2026-10-18

## Added

- **Five `epss_` tools** retrieve current/historical scores, inspect daily trajectories, discover threshold candidates, prioritize CVEs with caller-supplied CVSS severity, and explain EPSS interpretation and coverage.
- **Bounded lookup and provenance** preserve missing scores, deferred CVEs, exact-date history gaps, model attribution, and candidate-page continuation in structured and text output.
- **Client installation** supports stdio and Streamable HTTP, npm, Claude/Codex plugins, a portable MCPB bundle, and multi-architecture Docker images.

## Fixed

- **Sparse history** preserves valid anchor scores when FIRST omits daily observations. ([#1](https://github.com/cyanheads/first-epss-mcp-server/issues/1))
- **Dated CSV redirects** permit FIRST's documented daily score paths while retaining origin, path, address, and download bounds. ([#2](https://github.com/cyanheads/first-epss-mcp-server/issues/2))
