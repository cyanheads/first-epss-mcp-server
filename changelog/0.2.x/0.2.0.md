# 0.2.0 — 2026-10-28

## Added

- **`first-epss-guide` Agent Skill** — gates and workflows for the calling agent, served as `skill://first-epss-guide/SKILL.md` with the `skill://{+path}` template through `createApp({ skills })` (mcp-ts-core 0.13.18), and shipped under `skills/` in the npm package, Docker image, and `.mcpb`.
- **Agent Plugins root manifests** — root `plugin.json` and `mcp.json` (mcp-ts-core 0.13.18 template).

## Changed

- **Notice trailer** — Notices in `content[]` render as a Markdown blockquote with every line quoted, instead of a `**notice:**` line; `structuredContent.notice` is unchanged. The server now writes notices through `ctx.enrich.notice()`, and the 65,536-byte response budget models the new trailer.
- **HTTP session mode** — With `MCP_SESSION_MODE` unset, Streamable HTTP now runs stateless (previously `auto`, which resolved to stateful); an explicit `MCP_SESSION_MODE` still overrides. The Docker image and `.env.example` already set stateless.
- **`epss_query_threshold` description** — no longer claims candidate pages are ordered by EPSS: FIRST returns candidates in its own identifier order whatever order is requested, so the first page does not hold the highest scores. README and design notes match.
- **`.mcpb` bundle** — leaves out the framework's build-only files (mcp-ts-core 0.13.18 `clean-mcpb`, cyanheads/mcp-ts-core#791) and keeps the MCP SDK's skills runtime modules the skill needs (a local fix for cyanheads/mcp-ts-core#794).

## Fixed

- **HTTP memory growth under Bun** — the 0.1.3 release (mcp-ts-core 0.13.16) retained memory on every Streamable HTTP request under Bun, the runtime the Docker image runs; fixed by mcp-ts-core 0.13.17 (cyanheads/mcp-ts-core#786).
