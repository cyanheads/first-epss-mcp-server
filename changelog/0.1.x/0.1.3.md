# 0.1.3 — 2026-10-24

## Changed

- **`epss_query_threshold.limit`** accepts positive safe integers and clamps values above 10,000 before fetching, reporting requested/applied limits and echoing the applied limit. ([#14](https://github.com/cyanheads/first-epss-mcp-server/issues/14))
- **Hosted setup** documents the public Streamable HTTP endpoint and client-specific configuration; registry metadata includes the remote endpoint.
- **Runtime and tooling** update Bun pins 1.4.3 → 1.4.4 and synchronize framework contributor guidance and development checks.

## Fixed

- **Completion notices** distinguish exhausted offsets from missing scores and globally empty searches; empty exact-year notices describe only the candidate page, including its final page. ([#12](https://github.com/cyanheads/first-epss-mcp-server/issues/12))
- **Batch accounting** renders malformed identifiers as reversible JSON string literals in Markdown across unscored, withheld and deferred entries; response budgets include the final escaped notice trailer. ([#13](https://github.com/cyanheads/first-epss-mcp-server/issues/13))
