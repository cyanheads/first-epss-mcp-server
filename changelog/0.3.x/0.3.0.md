# 0.3.0 — 2026-11-21

## Breaking

- **`epss_query_threshold`** rejects `date` together with `addedWithinDays`, including windows that cover the full dated snapshot. Omit `date` for recent additions or keep another filter for a dated query. ([#16](https://github.com/cyanheads/first-epss-mcp-server/issues/16))

## Added

- **`epss_prioritize_cves`** reports each conflicting CVE and its distinct submitted severities. Large conflict reports identify every group by input row. ([#21](https://github.com/cyanheads/first-epss-mcp-server/issues/21))
- **Dated EPSS attribution** verifies model versions from matching daily CSV headers. History reports evidence from differing verified endpoints and flags gaps in transition coverage. ([#22](https://github.com/cyanheads/first-epss-mcp-server/issues/22))

## Changed

- **Runtime and tooling** require Bun 1.4.4 or later, document relative log paths and JWT claims, and update bundle cleanup and release validation.

## Fixed

- **Recent additions** keep `addedWithinDays` active by omitting `date` from every continuation page. ([#16](https://github.com/cyanheads/first-epss-mcp-server/issues/16))
- **CSV header reads** verify a first line that fits within both byte limits, even when upstream delivers additional compressed data in the same chunk. ([#17](https://github.com/cyanheads/first-epss-mcp-server/issues/17))
- **EPSS v1 coverage** explains why CVEs dated before 2017 can be absent and suggests retrying on or after 2022-02-04. ([#18](https://github.com/cyanheads/first-epss-mcp-server/issues/18))
